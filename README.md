# DealD — เปรียบเทียบราคา ง่าย ๆ

เว็บแอปเปรียบเทียบ **ราคาต่อหน่วย** ของสินค้า เพื่อดูว่าแบบไหนคุ้มกว่า
เน้นใช้งานบนมือถือ โหลดเร็ว ไม่ต้องสมัครสมาชิก ไม่มี Backend และติดตั้งลงหน้าจอโฮมได้เหมือนแอป

**เปิดใช้งาน:** https://thanyathee.github.io/DealD/

---

## DealD คืออะไร

เวลาซื้อของ ราคาที่ถูกกว่าไม่ได้แปลว่าคุ้มกว่าเสมอไป เพราะปริมาณต่างกัน
DealD ช่วยคำนวณให้อัตโนมัติด้วยสูตร:

```
ราคาต่อหน่วย = ราคา ÷ จำนวนหน่วย
```

แล้วบอกว่าแบบไหนราคาต่อหน่วยต่ำที่สุด ถูกกว่ากี่บาท กี่เปอร์เซ็นต์ และถ้าซื้อจริงจะประหยัดเท่าไร

### ความสามารถ

- เปรียบเทียบได้ตั้งแต่ **2 ถึง 5 แบบ** เลือกจำนวนได้จาก dropdown
- แสดง **ราคาต่อหน่วยแบบ realtime** ระหว่างพิมพ์
- สรุปผล: แบบที่คุ้มที่สุด, ส่วนต่างต่อหน่วย, เปอร์เซ็นต์ที่ถูกกว่า, เงินที่ประหยัดได้
- รองรับทศนิยม และการใส่ comma เช่น `1,000`
- ตรวจสอบข้อมูล พร้อมข้อความแจ้งเตือนภาษาไทย
- ใช้งานได้แบบ **ออฟไลน์** (PWA + Service Worker)
- Mobile first รองรับหน้าจอตั้งแต่ประมาณ 320px ขึ้นไป

## วิธีใช้งาน

1. เลือกจำนวนแบบที่ต้องการเปรียบเทียบ (ค่าเริ่มต้นคือ 2 แบบ)
2. กรอก **ราคา** และ **จำนวนหน่วย** ของแต่ละแบบ
3. ราคาต่อหน่วยจะคำนวณให้ทันทีใต้ช่องกรอก
4. กดปุ่ม **คำนวณ** เพื่อดูการ์ดสรุป
5. กดปุ่ม **ล้าง** เพื่อเริ่มใหม่

### ตัวอย่าง

| | ราคา | จำนวนหน่วย | ราคาต่อหน่วย |
|---|---|---|---|
| แบบ 1 | 100 บาท | 80 | 1.25 บาท |
| แบบ 2 | 200 บาท | 200 | 1 บาท |

ผลลัพธ์:

```
แบบ 2 ถูกกว่า
ถูกกว่าหน่วยละ            0.25 บาท
หรือถูกกว่า               20.00 %
ถ้าซื้อ 200 หน่วย จะประหยัด  50 บาท
```

## วิธีรันบนเครื่อง (Local)

DealD เป็น static site ล้วน ๆ จึงเปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย
(แต่ Service Worker จะไม่ทำงานบน `file://` ซึ่งไม่กระทบการคำนวณ)

หากต้องการทดสอบ PWA และ Service Worker ให้รันผ่าน local server:

```bash
git clone https://github.com/thanyathee/DealD.git
cd DealD

# เลือกอย่างใดอย่างหนึ่ง
python3 -m http.server 8000
# หรือ
npx http-server -p 8000
```

แล้วเปิด http://localhost:8000

> Service Worker ทำงานเฉพาะบน `https://` หรือ `localhost` เท่านั้น

## วิธี Deploy ด้วย GitHub Pages

โปรเจกต์นี้มี GitHub Actions workflow ให้แล้วที่ `.github/workflows/deploy.yml`
ซึ่งจะ deploy ให้อัตโนมัติทุกครั้งที่ push

ตั้งค่าครั้งแรกใน repository:

1. ไปที่ **Settings → Pages**
2. ที่หัวข้อ **Build and deployment → Source** เลือก **GitHub Actions**
3. กลับไปที่แท็บ **Actions** แล้วรอให้ workflow `Deploy to GitHub Pages` ทำงานจนเสร็จ
4. เปิดเว็บได้ที่ https://thanyathee.github.io/DealD/

> ทุก path ในโปรเจกต์เป็น **relative path** (`./style.css`, `./script.js`, `./manifest.json`)
> จึงทำงานได้ถูกต้องภายใต้ subpath `/DealD/` ของ GitHub Pages

## วิธีติดตั้งบนมือถือ (Add to Home Screen)

### iPhone / iPad (Safari)

1. เปิด https://thanyathee.github.io/DealD/ ด้วย **Safari** (ต้องเป็น Safari เท่านั้น)
2. กดปุ่ม **แชร์** (ไอคอนสี่เหลี่ยมมีลูกศรขึ้น) ที่แถบด้านล่าง
3. เลื่อนลงแล้วเลือก **เพิ่มไปยังหน้าจอโฮม / Add to Home Screen**
4. กด **เพิ่ม / Add**

### Android (Chrome)

1. เปิด https://thanyathee.github.io/DealD/ ด้วย **Chrome**
2. กดปุ่มเมนู **⋮** มุมขวาบน
3. เลือก **ติดตั้งแอป / Install app** หรือ **เพิ่มลงในหน้าจอหลัก / Add to Home screen**
4. กด **ติดตั้ง / Install**

เมื่อติดตั้งแล้วจะเปิดแบบเต็มจอเหมือนแอป และใช้งานได้แม้ไม่มีอินเทอร์เน็ต

## โครงสร้างโปรเจกต์

```
DealD/
├── index.html              # โครงหน้าเว็บ + meta สำหรับ PWA/SEO
├── style.css               # สไตล์ทั้งหมด (mobile first)
├── script.js               # ตรรกะการคำนวณ ตรวจสอบข้อมูล และลงทะเบียน Service Worker
├── manifest.json           # Web App Manifest สำหรับติดตั้งเป็นแอป
├── service-worker.js       # แคชไฟล์เพื่อให้ใช้งานออฟไลน์ได้
├── .nojekyll               # บอก GitHub Pages ว่าไม่ต้องประมวลผลด้วย Jekyll
├── README.md
│
├── assets/
│   ├── logo.png            # Master Logo (1024×1024) ต้นฉบับของไอคอนทุกขนาด
│   └── icons/
│       ├── favicon-32.png
│       ├── apple-touch-icon.png     # 180×180 พื้นทึบ สำหรับ iOS
│       ├── icon-192.png             # ใช้เป็นโลโก้บน header ด้วย
│       ├── icon-512.png
│       └── icon-maskable-512.png    # ไอคอนแบบ maskable สำหรับ Android
│
└── .github/
    └── workflows/
        └── deploy.yml      # deploy ขึ้น GitHub Pages อัตโนมัติ
```

## เทคโนโลยี

HTML + CSS + Vanilla JavaScript ล้วน ๆ ไม่มี framework ไม่มี dependency
ไม่มี backend ไม่มีฐานข้อมูล และไม่มีการเก็บข้อมูลผู้ใช้ ทุกอย่างคำนวณในเบราว์เซอร์
